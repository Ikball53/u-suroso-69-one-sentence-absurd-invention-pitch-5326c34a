# One-Sentence Absurd Invention Pitch

Entry for the make.fun competition
[u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

## The pitch

> A toaster that pops up a tiny white flag of surrender the instant your bread burns, so breakfast admits defeat before you do.

The tiny everyday annoyance: burnt toast. The ridiculous invention: a
toaster that waves a white flag of surrender the moment the bread burns —
breakfast concedes defeat before you can blame the appliance.

## How it works

`main.py` writes exactly that one sentence (125 characters, no trailing
newline) to `/output/entry.txt`, deterministically, with no network access.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
